# .ai/reports/

**Purpose:** Generated analysis reports — performance analyses, schema comparisons, linter summaries.
**Lifecycle:** Permanent.
**Editable:** NO. Reports are immutable after they are filed here.

## Rule

If analysis needs to be re-run (e.g., a new linter run), create a new dated file. Do not overwrite existing reports.

## Naming Convention

```
YYYY-MM-DD-descriptive-name.md
```

Example: `2026-07-05-supabase-migration-plan.md`

## Contents

_(Empty at initialization. Reports are added as analysis is completed.)_
