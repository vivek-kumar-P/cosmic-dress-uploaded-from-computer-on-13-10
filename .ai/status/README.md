# .ai/status/

**Purpose:** Living project dashboard. Updated at the start and end of every AI session.
**Lifecycle:** Permanent file, but contents change frequently.
**Editable:** Yes — this is the most frequently updated file in the `.ai/` directory.

## Contents

| File | Description |
|------|-------------|
| [`PROJECT_STATUS.md`](./PROJECT_STATUS.md) | Current branch, milestone, last task, active tasks, blocked tasks, pending migrations, recent decisions, next priorities |

## Update Frequency

- **Start of session:** Read to understand where the project is.
- **End of session:** Update with what changed, what is pending, and next priorities.
- **After every migration:** Update pending/completed migration lists.
- **After every significant decision:** Record in the `Recent Decisions` section.
