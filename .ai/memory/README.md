# .ai/memory/

**Purpose:** Permanent log of key architectural decisions made during AI sessions.
**Lifecycle:** Permanent. Append-only.
**Editable:** Yes — new decisions are appended. Existing entries are never edited or deleted.

## Contents

| File | Description |
|------|-------------|
| [`DECISIONS.md`](./DECISIONS.md) | Chronological log of architectural and security decisions — what was decided, why, and when |

## Rule

Every significant decision that affects the architecture, security model, or database schema should be logged here with:
- **Date**
- **Decision** (what was decided)
- **Context** (what problem it solves)
- **Alternatives considered**
- **Consequences**
